# Downloads

| Name                  | Download Link                                                | Description                                                                                                                                                               |
|-----------------------|--------------------------------------------------------------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Ikaraos               | [Ikaraos Download Page](http://www.ikaros-project.org/downloads/) | An infrastructure for system-level brain modeling. Authors: Contributions by [more than 20 people](http://www.ikaros-project.org/people/). Added 2003-11-21                  |
| Macoglossum Source Code | [C++ Source](http://www.lucs.lu.se/Downloads/macroglossum.cpp)    | Source code for simulations reported at SAB06. Authors: Christian Balkenius and Anna Balkenius. Added 2006-10-21                                                            |
| Deilephila Source Code  | [C++ Source](http://www.lucs.lu.se/Downloads/Deilephila.cc)        | Source code for simulations reported at SAB02 and in *Adaptive Behavior*, 2003. Authors: Christian Balkenius and Anna Balkenius. Added 2003-07-24                          |
| GridLearning          | [Mac OS 9](http://www.lucs.lu.se/Downloads/GridLearning.sea.hqx)      | A simple reinforcement learning implementation. Written in 1996.                                                                                                           |
| BERRY III             | [Mac OS 9](http://www.lucs.lu.se/Downloads/BERRY.sea.hqx)              | Simulator used in my PhD thesis. Written in 1993-1995. IMPORTANT: Use the NO-FPU version on OS X with Classic. Unlikely to run on any computer as of 2008.                     |
